# rasio-seru-mtk-kelas6
Rasio adalah materi yang mempelajari cara membandingkan dua besaran atau jumlah. Siswa belajar memahami, menuliskan, menyederhanakan, dan menentukan rasio senilai serta menerapkannya dalam kehidupan sehari-hari, seperti membandingkan jumlah benda, membuat resep, dan menyelesaikan masalah sederhana.
